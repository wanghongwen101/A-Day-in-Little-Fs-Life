# A Day in Little F's Life

## About the Game

*A Day in Little F's Life* is a narrative-driven, choice-based game developed using Python and Pygame.

The story follows Little F, a Chinese high school student who wants to attend a manga signing event. However, his mother agrees to let him go only if he can survive an entire school week without getting her called into school.

Throughout the week, players must navigate classroom activities, family expectations, friendships, and difficult decisions. Some choices have consequences that only become apparent several days later.

## Features

- Branching narrative across six in-game days
- Hunger, Energy, and Mood management
- Multiple endings influenced by player decisions
- Character portraits and Animalese-style dialogue sounds
- Animated transitions and pixel-art interfaces
- A courtroom-inspired final chapter with an evidence system

## How to Play

1. Make decisions during classroom events and story interactions.
2. Keep Hunger, Energy, and Mood above zero.
3. Pay attention to conversations and choices, as they may affect future events.
4. Survive the week and discover whether Little F can attend the signing event.

## Controls

- **Mouse:** Select dialogue options and interact with objects.
- **Space:** Advance dialogue.
- **F1:** Open the developer debug menu.

## How to Run

1. Download the repository as a ZIP file and extract it.
2. Install Python 3 and the required libraries:

   ```bash
   pip install pygame-ce numpy
   ```

3. Keep `main.py` and the `assets` folder in the same directory.
4. Run:

   ```bash
   python main.py
   ```

## Technologies Used

This project was developed as a creative interactive media prototype.

The game explores the pressures of school life, family expectations, and the consequences of everyday choices through humor and branching storytelling.
